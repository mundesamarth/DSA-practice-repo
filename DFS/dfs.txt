OPERATIONS
| What you want           | JavaScript               |
| ----------------------- | ------------------------ |
| Node's value            | `node.val`               |
| Left child              | `node.left`              |
| Right child             | `node.right`             |
| Move left               | `node = node.left`       |
| Move right              | `node = node.right`      |
| Check if node exists    | `node !== null`          |
| Check left exists       | `node.left !== null`     |
| Check right exists      | `node.right !== null`    |
| Create node             | `new TreeNode(value)`    |
| Change left connection  | `node.left = something`  |
| Change right connection | `node.right = something` |


The Three DFS traversal patterns
Preorder:   NODE → LEFT → RIGHT

Inorder:    LEFT → NODE → RIGHT

Postorder:  LEFT → RIGHT → NODE
