-Binary Search is a searching algorithm that finds a target in a sorted search space by repeatedly cutting the search space in half.

const binarySearch = (nums, target) => {
    let left = 0;
    let right = nums.length - 1;

    while (left <= right) {
        let mid = Math.floor((left + right) / 2);

        if (nums[mid] === target) {
            return mid;
        }

        if (nums[mid] < target) {
            left = mid + 1;
        } else {
            right = mid - 1;
        }
    }

    return -1;
};

left              → beginning of search space
right             → end of search space

mid               → middle index
nums[mid]         → middle value

left = mid + 1    → throw away left half
right = mid - 1   → throw away right half

left <= right     → search space still exists
left > right      → search space is empty
